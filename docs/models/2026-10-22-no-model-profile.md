# Model and provider card

SchemaRoute does not run an LLM or contact a provider. The three profiles are static interpretations of provider documentation accessed on 2026-10-22.

## Intended use

Use the tool as an offline CI preflight before a schema is deployed across a declared provider fallback route.

## Non-goals

It does not measure model quality, semantic accuracy, live schema adherence, latency, cost, refusals, safety, authorization, or provider availability. It does not replace response validation.
